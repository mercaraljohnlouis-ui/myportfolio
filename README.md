Instructors at the CMDI faculty were spending too much of their limited class time completing attendance, so I set out to build an attendance system that would make the process faster. As the developer, I handled the project from start to finish: I gathered requirements from the faculty, planned the system, designed the interface, developed it, and deployed it. I built it with Laravel, PHP, SQL, HTML, and CSS. The result was a 34% reduction in the time instructors spent on attendance, along with a user acceptance result of 4.5. The biggest lesson I took away was to spend more time reviewing and evaluating the framework before committing to it, since that early decision shapes the rest of the development, and I would apply that step from the beginning of future projects.
